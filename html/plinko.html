Roat Pkz – Provably Fair Plinko Verifier

This page hashes client_seed + ":" + server_seed + ":" + nonce with SHA-256 and reads one bit of the hash per row of pegs, starting at the most significant bit of the first byte: a 1 sends the ball right, a 0 sends it left. The slot is the number of times it went right, and the multiplier comes from the game's pay table for that risk and number of rows. It is the same algorithm as the Roat Pkz server.

Each ball you drop uses the next nonce, starting at 1 for a new server seed, so the Verify button in the game opens this page on your last ball. To check an earlier ball, change the nonce, and set the rows and the risk to what the board had when that ball dropped. A win is paid at the slot's multiplier unless that would pass the max win per ball shown in the game's Rules box.

This HTML page is fully self-contained and works entirely offline – it never communicates with any external server.
